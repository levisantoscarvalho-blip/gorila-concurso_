# Gorila Concurso

Plataforma web para quem estuda para concursos públicos: o usuário escolhe um concurso, registra os dias de estudo e acompanha o histórico.

## O que faz hoje

- Escolha de um concurso próximo da região do usuário.
- Mapa do histórico de estudo, com os dias ativos em destaque.
- Cartão de ponto de estudo, com foto.
- Robô auditor, que confere e atualiza os dados automaticamente.

## Situação atual

Protótipo em desenvolvimento, rodando apenas localmente (ainda sem hospedagem nem domínio) e com dados de teste. Os próximos passos são a escolha de cursos, a resolução de questões, salvar os estudos por usuário e publicar o site online. A visão é que o projeto se torne uma empresa.

## Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/levisantoscarvalho-blip/gorila-concurso_.git
   ```
2. Abra a pasta do projeto no [VS Code](https://code.visualstudio.com/).
3. Instale a extensão **Live Server**.
4. Abra o arquivo HTML principal da pasta `Html_Gorilaconcurso` e clique em **Go Live** (canto inferior direito do VS Code).
5. O site abre no navegador, em um endereço local.
